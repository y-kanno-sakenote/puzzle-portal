# 車をだせ！ 決定ログ（直近が上）

| 日付 | 決定 | 捨てた案 | 理由 |
|---|---|---|---|
| 2026-09-06 | クリア判定は「赤い車が右端(x=4)に着いた時点」。そこから盤外へ滑り出すのは演出で、手数に数えない | 盤外へ抜ける操作を1手として数える | BFSの最短手数と画面の手数が1ずれると「最短」の表示が嘘になる。1回のドラッグで右端へ着けばその手でクリア＝数え方が自然 |
| 2026-09-06 | 上級（19手以上）は山登り（難しい盤を少しずつ崩して探す）で作る | ランダム生成の試行回数を増やすだけ | ランダム4000本では上級0本・中級7本しか出なかった。山登りなら同じ時間で19〜28手が揃う。難度ラベルは実測の最短手数からのみ付ける |
| 2026-09-06 | 日本酒テーマを入れず、素の「車」で作る | 酒瓶・配達トラックに置き換える / 蔵の中の樽を動かす | 依頼は「ラッシュアワー的な車を外に出すゲーム」。テーマは後から着せ替えられるが、操作の気持ちよさは着せ替えでは直らない。まず素で成立させる |
| 2026-09-06 | レベルは事前生成（BFS検証済み40本）を埋め込む。ブラウザ内でのランダム生成はしない | ブラウザ内で毎回生成 / 手で盤面を書く | 手書きは最短手数を保証できない。ブラウザ内生成は解ける保証と難度調整をその場でやることになり、初日の複雑さとして重い |
| 2026-09-06 | 1手＝1台を好きな距離だけ滑らせる（標準ルール） | 1マス移動＝1手 | 標準のラッシュアワーと同じ数え方でないと「最短手数」の比較に意味がなくなる |
