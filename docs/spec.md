# 車をだせ！ 仕様 v0.1（2026-09-06・叩き台）

## 完成条件（観測可能）
初見の人が (1) 開いてすぐ盤面が見え (2) 指かマウスで車を滑らせ (3) 赤い車を右の出口から出してクリアし
(4) 次のレベルへ進め (5) 閉じて開き直しても進み具合が残っている。スマホの縦画面で片手で遊べる。

## 盤面
- 6×6マス。座標は左上が (0,0)、x が右、y が下
- 出口: 右端、y=2 の行（上から3行目）。赤い車はこの行に横向きで置く
- 車: 長さ2（車）と長さ3（トラック）。横向きは左右、縦向きは上下にしか動かない
- 壁・穴・特殊マスは無し（足さない）

## 操作
- ドラッグで滑らせる（Pointer Events。マウスとタッチ両対応）。離した位置に最も近いマスへスナップ
- 他の車を跨げない。ドラッグ中も他の車に当たった所で止まる
- 赤い車が右端まで来て出口方向へドラッグすると盤外へ抜けてクリア
- ボタンは「もどす（1手戻る）」「はじめから」の2つだけ。クリア後に「つぎへ」

## 手数
- 1手＝1台を動かすこと（何マス滑らせても1手。同じ車を続けて動かすのは別の手）
- 画面には「手数」と「最短」を並べて出す。最短以内で解けたときだけ小さく印（★）

## レベル
- `tools/gen_levels.py` がランダム配置→BFS で最短手数を求め、条件を満たすものだけ出力する
  - 解ける／最短3手以上／全部の車が盤に収まる／重なり無し
  - 難度は最短手数で4段階: 入門 3〜5 / 初級 6〜10 / 中級 11〜18 / 上級 19〜
- 各段階10本、計40本を `index.html` に文字列で埋め込む（36文字の盤面記法: `o`=空, `A`=赤い車, `B`〜=他の車。同じ文字が並ぶ長さで車の長さと向きが決まる）
- レベル順は最短手数の昇順。番号でなく段階名と何本目かで見せる（例「初級 3」）

## 保存
- localStorage に「クリア済みレベル」と「最後に開いたレベル」だけ。数値の履歴やタイムは持たない

## 足さないもの（v0.1）
- ヒント／自動解答／タイマー／スコア／ランキング／効果音／広告
- レベルエディタ、ランダム無限モード（要望が出たら決定ログを経て検討）
