# はやつかみ 仕様 v0.2（2026-09-13・叩き台）

## 遊び方（お化けキャッチの仕組みを借りる。名称・意匠は使わない）
スマホを机に置き、二人が向かい合って座る。画面の中央に5つの品が横一列に並ぶ。
札が1枚めくれるたび、**正しい品を先に自分の側へ引き寄せた方がその札を取る**。

## 品と札
- 品は5つ。形と色が1対1で決まっている
  - 赤いはな（丸い花びら4枚）／青いダイヤ（菱形）／黄色いろっかく（六角形）／緑のリボン（蝶ネクタイ）／黒いわ（輪）
- **5つとも180度回すと自分自身に重なる形に限る**。向かい合って遊ぶので中央の品は上の人には
  上下逆に見える。逆さまでも同じに見える形でないと、見つける速さに差が出て不公平になる。
  形を足したり差し替えたりするときは `tools/check_symmetry.py` で必ず点検する（IoU 0.999 以上を合格とする）
- 札には2つの絵柄が描かれる。**形は重複しない、色も重複しない**
- 正解の決まりは2通りだけ
  1. **そのままの品がいるとき**: 札の絵柄のうち、形と色が本来の組み合わせと一致するものが1つあれば、**その品**が正解
  2. **いないとき**: 札に**形としても色としても出ていない**品がちょうど1つ残る。**それ**が正解
- 札は全部で機械生成し、正解が1つに定まることを検証したものだけ使う。1の札と2の札を混ぜる

## 画面（向かい合い専用・横向き）
- 机に置いて使う。**横向き**（`orientation` は強制しない。縦のままなら「横にしてください」と1行出す）
- 中央に品が5つ横一列。上下に札の表示（同じ札を上下に出し、**上側は180度回して**相手から読めるようにする）
- 各プレイヤーの取った枚数を自分側の端に表示（相手側の数字も180度回す）

## 操作
- 品を**自分の側へ短く引く**（スワイプ）と取ったことになる。上へ引けば上の人、下へ引けば下の人
- 2本の指を別々に追う（Pointer Events の pointerId 別）
- **先に引き切った方がその札を取る**（引く距離のしきい値を先に越えた方。触った順は見ない）。
  しきい値を越えた瞬間にその場で決まる。待ち時間も猶予窓も置かない。以降のその札への引きは無視する
- **札が出る前から品に指を置いてもよいが、得はしない**。しきい値を越えられるのは札が出た後だけで、
  札が出た瞬間に、そのとき押されている指の起点はその場に置き直される（置きっぱなしでは引いたことにならない）
- **札が変わったら、そのとき触れている指はいったん無効になる**。いったん離して触り直すまで引けない
  （前の札で引いた指が次の札へ誤爆しないようにするため）
- 正しい品を引いたら札を取る。間違えたら**自分の持ち札を1枚相手に渡す**（0枚なら何も起きない。札は据え置き）
- 次の札は**始まりの合図のあと**に出る。札が取られると中央に大きく **3 → 2 → 1** が出て、
  0 になった瞬間に次の札が出る（1数字 1.0 秒・合計 3 秒。取られてから黙って 0.6 秒待つのをこれに置き換えた）。
  **1局の最初（「はじめる」を押した後と「もう一回」→「はじめる」の後）も同じ合図から始める**
- 合図は**同じ数字を2つ**並べ、片方を180度回して向かい合う二人のどちらからも読めるようにする。
  中央の品にかぶらないよう、その両脇の隙間に置く。数字だけで、音も動きも足さない
- **合図は制限時間ではない**（札が出る瞬間を二人に予告するだけ。答えるまでの時間は区切らない）。
  合図の間は札が場に無いので、品に触れても引いても何も起きない。札が出た瞬間に押されたままの指の起点が
  その場に置き直されるのは上の決まりのまま

## はじめる（2026-09-14 追加）
- ページを開いた直後は**札を配らず**、画面の中央に「はじめる」ボタンだけを出す。
  押すと合図（3→2→1）が始まり、0 で最初の札が出る。二人が座って構える前に勝負が始まらないようにするため
- ボタンは**画面のちょうど真ん中に1つ**。同じ文字を上下2つ並べ上側を180度回すので、
  ボタン全体が180度回しても同じに見える（中央の品と同じ決まり）＝向かい合う二人のどちらからも読めて押せる
- 決着後の「もう一回」は**また「はじめる」から**（決着した直後にいきなり始まらない）
- ルール説明の板は「はじめる」より上に重なっているので、**板が出ている間は押せない＝始まらない**。閉じると押せる
- 「はじめる」を押す前も品には触れられるが、札が場に無いので何も起きない（合図の間と同じ扱い）。
  ボタンの覆いは見た目だけで指は通す

## 勝敗
- 先に **7枚** 取った方が勝ち。決着したら「もう一回」
- 制限時間は設けない（始まりの合図は札が出る瞬間の予告であって、答えるまでの時間を区切るものではない）

## 保存
- localStorage キー `hayatsukami`: `{wins:{top:n, bottom:n}}` だけ。途中経過は保存しない（対面で一気に遊ぶもの）

## 足さないもの（v0.1）
- 制限時間／連打／効果音／3人以上／上級札（一致が2つ）／オンライン対戦／ひとり用の練習モード

## ルール説明（2026-09-13 追加）
- 初回だけ盤の上に薄い板で4行のルールを出し、タップで消す。見出しの横の「？」でいつでも出し直せる
- 板は**同じ文を上下2枚**（片方は180度回す）出し、向かい合う二人のどちらからも正立して読める
- 読んだかどうかは localStorage の `seen`（1）で覚える。壊れた値が入っていても起動は落ちない
