# 車をだせ！ AIガイドライン

## 第0章 なぜ
ラッシュアワー型パズルを、単一HTMLで「開いて3秒で遊べる」形にする。仕掛けを足さず、盤面と操作の気持ちよさだけで成立させる実験。

## 触るなリスト
- 盤6×6・出口の位置（右端・3行目）・赤い車の行
- 1手の定義（1台を滑らせる＝1手）
- 埋め込みレベルの文字列（`tools/gen_levels.py` の出力以外で書き換えない。手直しするなら生成器を直して再生成）
- 「足さないもの」の一覧（spec.md）

## 第2章 事故と学び（事故のたびに育てる）
- 2026-09-07 指ドラッグで離した瞬間に車が元の位置へ戻ってから滑る（ガクつき）。原因: pointerup で transform を消してから left を書き換えていた。学び: **離した位置を起点に残りの距離だけ滑らせる**（先に新しい left を遷移なしで置き、指との差分を transform に残して 0 へ遷移）。合成イベントでは気づけない。実機で指で触るまで操作の気持ちよさは確かめられない
