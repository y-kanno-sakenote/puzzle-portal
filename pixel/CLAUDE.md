# ピクセル（pixel）

行と列の数字を手がかりにマスを塗り、隠されたドット絵を浮かび上がらせるお絵描きロジック（ノノグラム）。
単一HTML（`index.html`）。数独・星おきと同じ**一意解スキーム**。コードは共有しない。

## 正典地図
- 仕様: `docs/spec.md`／決定ログ: `docs/decision_log.md`
- 生成器: `tools/gen_puzzles.py`（一意解の検証と論理的解法判定を通ったものだけ埋め込む）
- 独立検証: `tools/qa_check.py`（独立ソルバーによる全問再検証）

## 憲法（変えない原則）
- 解は必ず一つ。仮定（背理法・あてずっぽう）なしで解ける論理的な問題だけを埋め込む。手で問題を書かない
- ルールは外周の数字だけ。ライフ・ミス数・タイマー・自動×埋めは足さない
- 遊んでいる最中に正誤を教えない。すべての正解マスが塗られた瞬間に絵が完成する
- 本家（ピクロス等）の商標・キャラ・他社の問題データは使わない。オリジナルモチーフだけ
- 実機（スマホ）で遊ぶまで「完成」と言わない。迷って決めた判断が出たら決定ログへの記録を促すこと
