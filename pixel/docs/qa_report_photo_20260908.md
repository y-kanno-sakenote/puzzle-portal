## 4. 難度ラベルの分布 — 偏りを実測（合否ではなく数値報告）
実運用と同じ経路（stretch→otsu二値化→ラインソルバー→だめなら修復）で、なめらかブロブ画像を各N100枚生成しDを実測。

| N | 上級率 | D: min / p25 / p50 / p75 / max |
|---|---|---|
| 15 | 75% | 124 / 158 / 204 / 221 / 310 |
| 20 | 98% | 154 / 240 / 279 / 314 / 438 |
| 25 | 100% | 176 / 330 / 374 / 410 / 556 |

現行の固定閾値（入門≤118/初級≤128/中級≤156/それ以上=上級。index.htmlの5×5・10×10の実測レンジをそのまま転用）は、決定ログ自身が懸念していた通り**N=20/25でほぼ全問「上級」に張り付く**（N=20で98%、N=25で100%）。またindex.html自身のtier割当は固定閾値ではなくサイズ内での**D順位による相対割当**（10×10を上位/中位/下位に三分割）であり、43問中9問でこの相対tierと固定閾値tierが食い違う（`かんむり`等6問が入門判定になるべきところ初級、`カメラ`等3問が中級/上級のところ特級/達人相当）。「生成器と同じ指標・閾値」という記述は指標(D)は一致するが閾値の使い方（絶対値 vs 相対順位）が生成器と異なる。

**閾値案（この実測ベースの叩き台。実装はしない）**: サイズNごとに四分位で刻む
- N=15: 入門≤158 / 初級≤204 / 中級≤221 / 上級>221
- N=20: 入門≤240 / 初級≤279 / 中級≤314 / 上級>314
- N=25: 入門≤330 / 初級≤374 / 中級≤410 / 上級>410

足さない案: 4段階を維持せず「N=20/25は最初から2段階（中級/上級）でよい」という割り切りも成立する（サンプル数を増やすほど閾値は動くため、どのみち叩き台）。
