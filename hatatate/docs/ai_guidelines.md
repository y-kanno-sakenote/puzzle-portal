# はたたて AIガイドライン

## 第0章 なぜ
数字から隠れたものを当てる遊び（地雷さがしの類）の面白さは推理なのに、最初の一手と終盤の二択で運に負ける。始まりの一部を開けておき、推理だけで最後まで開けられる盤だけを出して、運を消す。
ナンプレと同じく「推論の強さ」で段を分ける。

## 触るなリスト
- 採用条件「段階ソルバーで全安全マスが開ける」。検証していない盤を埋め込まない
- 推論の段の定義（段1〜4・段1に「のこり」だけで決まる場合を含む・各回まとめて適用）。Python（`tools/gen_levels.py`）と JS（`window.Hatatate.solve`）は同じ定義で、変えるなら両方を直して40問の一致を確かめる
- 規則（0の連鎖・🚩は答えに関わらない・おちた→もどすで続ける・「のこり」の表示）
- 埋め込みレベル（`/* LEVELS-BEGIN */`〜`/* LEVELS-END */`）。手直しするなら生成器を直して再生成し `--keep tools/levels.json --embed index.html` で貼る
- 進み具合の保存キー `hatatate` と `{cleared:{idx:1}, last}` の形（入口 `../index.html` が読む）
- レベルの並び順（クリア記録が index 依存。段を足すなら末尾に追記）
- 「足さないもの」の一覧（spec.md）
