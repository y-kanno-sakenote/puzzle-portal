| 2026-10-13 | 採用条件に「始まりに見える盤（開いたマスの位置と数字、左右・上下反転・180度で同一視）が同じ段の既採用と同じなら採らない」を足し、10問の選びで始まりのマスを3×3の区画ごとに2問までに散らす。段の中の並びの鍵を spec に正確に書き、入門も段1の回数で並べる。40問を作り直し | 🕳️配置の Jaccard だけで判定 / 並びは spec の大まかな書き方のまま | qa：入門1〜3、入門8〜9が始まりに見える盤まで同じで、遊び手には同じ問題。入口を最小限にすると角の4マスの入口ばかりになり重なりやすい。並びの実データに spec に無い鍵（中級の段2の回数など）が入っていた |
| 2026-10-13 | 踏んではいけないものを🕳️（落とし穴）、踏んだときを「おちた！」に（ui係）。数字の色は1青・2墨・3以上赤。カード説明は「数字を読んで穴をよける」。「マインスイーパ」「推理パズル」は画面に出さない | 🌰（栗拾いの集めるものに見える）／💣（箱の穏やかさに合わない）／緑を足す | 名前「はたたて」＝穴に旗を立てて目印、と合う。推理パズルはニコリの登録商標（第16類） |
| 2026-10-13 | 上級＝最も強いのが段4、かつ段3も1回以上 | 段4が要れば上級（段3なし可）/ 段3を3回以上で上級 | 段4は候補のほぼ全部で終盤の1回だけ（上級候補で段4が2回以上は0）。段4だけだと段3を使わない盤ばかりになり中級より易しく感じうる。段3を多用する盤は少なく（3回以上は1割未満）、10問そろわない |
| 2026-10-13 | 盤全体の「のこり」だけで決まる場合（のこり0→閉じたマスは全部安全／のこり＝閉じたマスの数→全部地雷）は段1 | 「のこり」を使えば何でも段4 | 終盤の「のこり0なら残りは全部安全」は数字1つ分の推理と同じ重さ。これを段4にすると入門〜中級の多くが上級に化ける。段4は「のこり」を数字と組み合わせる場面に限る |
| 2026-10-13 | 押しやすさの最低ラインを幅360pxでマス36px以上とし、盤を 入門6×8・初級8×10・中級8×12・上級9×14（列×行）にする | 叩き台の 中級9×12・上級10×14（上級は34px） | 10列だと幅360pxで34px。44pxは6〜7列でしか取れず、上級の広さが出ない。36pxは指先でぎりぎり押し分けられる大きさ（実機で要確認） |
