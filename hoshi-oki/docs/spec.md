# 星おき 仕様 v0.1（2026-09-08・叩き台）

## 完成条件（観測可能）
初見の人が (1) 開いてすぐ色分けされた盤と3行のルールが見え (2) マスを押して×と★を置き (3) ★が N 個そろった瞬間に正誤が分かり (4) 次へ進め (5) 途中で閉じても続きから再開できる。スマホ縦・片手。

## 盤面
- N×N。入門 5〜6／初級 7／中級 8／上級 9（叩き台）。N 個の領域はそれぞれ連結で、色分けして描く（隣接領域が同じ色にならない配色。色は飾りで、領域の境界は太線でも示す）
- 問題記法: `{"n":7,"regions":"49文字（領域id a〜）","solution":"49文字（★の位置を1、他を0）","tier":"入門"}`

## ルール（画面に3行で常時表示）
- どの色にも★を1つ
- どの行・列にも★を1つ
- ★どうしは、斜めもふくめて隣り合わない

## 操作
- マスをタップで 空 → × → ★ → 空 と巡る（×は「ここには置けない」のメモ。判定に無関係）
- 空マスから指でなぞると×を連続で置ける（×の上をなぞると消す）。★はタップでしか置けない
- ボタン: 「もどす」「はじめから」
- ★が N 個になった瞬間に判定。正解→「クリア！」→「つぎへ」。違えば「どこか違う」を1行（場所は言わない。次の操作で消える）。N 個未満なら何も言わない

## 生成
- `tools/gen_puzzles.py`: 解（各行・各列に1つ、隣接しない★の配置＝非隣接の順列）をランダムに作る→各★を種にして領域をランダムに育て、全マスを N 領域に分ける→ソルバーで解を2つまで数えて一意なら採用
- 難度: 論理ソルバー（行・列・領域の候補が1つ／ある領域の候補が1行か1列に収まれば他を消す／隣接で消す）で解き切れるかと、バックトラックの分岐数で4段階。閾値は実測で決めて書き戻す。各段階10本、計40本

## 保存
- localStorage キー `hoshi-oki`: `{cleared:{idx:1}, last:idx, grid:{idx:"N×N文字（0空/1×/2★）"}}`。try/catch、壊れていれば初期化

## 足さないもの（v0.1）
- ライフ／ミス数／タイマー／間違いの赤表示／ヒント／自動解答／効果音／猫・王冠などのキャラ
