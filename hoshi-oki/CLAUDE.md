# 星おき（hoshi-oki）

N×N の盤が N 個の色の領域に分かれている。各領域・各行・各列に★をちょうど1つ置く。★どうしは斜めも含めて隣り合わない。
単一HTML（`index.html`）。数独・窓わけと同じ**一意解スキーム**。コードは共有しない。

## 正典地図
- 仕様: `docs/spec.md`／AIガイドライン: `docs/ai_guidelines.md`／決定ログ: `docs/decision_log.md`
- 生成器: `tools/gen_puzzles.py`（一意解の検証と難度判定を通ったものだけ埋め込む）
- 思想: `../../../template/owner_context.md`（コピー禁止）

## 憲法（変えない原則）
- 解は必ず一つ。検証していない問題は埋め込まない。手で問題を書かない
- ルールは3つだけ（領域・行・列に1つ／隣接禁止）。ライフ・ミス数・タイマーは足さない
- 遊んでいる最中に正誤を教えない。★が N 個置かれたときだけ判定する
- 本家（Meowdoku／Queens 等）の名前・猫・王冠・文言は使わない。仕組みだけ
- 実機（スマホ）で遊ぶまで「完成」と言わない。迷って決めた判断が出たら決定ログへの記録を促すこと
