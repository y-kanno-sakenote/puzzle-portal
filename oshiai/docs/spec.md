# おしあい 仕様 v0.2（2026-10-15・叩き台）

v0.2：宝は1人2つ（自分の色の宝 → 真ん中の共通の宝）、共通の宝を先に拾った方の勝ち、打ち切り40手（オーナー決定「冗長になりすぎる」への対策。v0.1 は自分の宝①②③を先に3つ・60手）

おしだし（ひとり用）の押し込みの仕組みで、二人が宝を取りあう。スマホを机に置き、二人が向かい合って座る。

## 盤（毎回ランダム）
- 5×5。タイルは3種（直線・かど・三叉＝3:4:3、おしだしと同じ）。押せる列は1つおき（0始まりで1・3の行と列）。偶数行かつ偶数列のマスは動かない
- **盤の中心について180度回転で対称**：マス i のタイルを180度回したものがマス 24−i に入る。中心（12）は自分自身と対になるので直線だけ（十字のタイルは無いので直線のまま）
- **四隅は内向きのかどに固定**（四隅は動かないので、外向きだと駒が出られなくなる）
- 駒：手前の人＝青がマス20（手前から見て左下）、向こうの人＝赤がマス4（向こうから見て左下）
- 宝は1人2つ。**1つ目は自分の色の宝**：四隅と中心を除く10対から1対を選び、対の片方を青、もう片方を赤の宝にする。**2つ目は二人共通の宝（金）**：盤の真ん中（12）。真ん中は動かないマスなので押し出されず、180度対称で両者に同じ条件になる唯一のマス
- はじめから自分の宝に道がつながっている盤は配り直す（押さずに拾えてしまう）
- 手持ち：1枚（3種からランダム）を二人で共有

## 手番
1. **押し込む（必ず）**：手持ちを押し込み口から入れ、列を1マスずらす。押し出された1枚（と乗っている宝）が**次の人の手持ち**になる。押す前に手持ちはタップで何度でも回せる
   - **相手がたった今押した列を、その口の反対側から押し戻すのは禁止**（その矢印を薄くする）。押し込み口は8つなので、打てる押し込みは毎回7つ以上ある
   - 押すと**両方の駒・両方の宝**が列と一緒に動く。押し出された宝は手持ちに乗り、次の押し込みで入口のマスに入る。押し出された駒は反対の端（入ってきた1枚の上）へ回り込む
2. **自分の駒を動かす**：道がつながっている範囲の好きなマスへ（届くマスを薄く塗る）。自分の駒のマスをタップすると「とどまる」
   - **次に狙うマスで止まったら拾う**（途中で通っただけでは拾わない）。順番は自分の宝 → 共通の宝。相手の色の宝は拾えない。自分の宝を拾う前は共通の宝に止まっても拾えない。駒どうし・駒と宝は同じマスに乗ってよい

## 勝ち
- **共通の宝を先に拾った方の勝ち**（その時点で終局。相手が自分の宝をまだ拾っていなくても）
- 二人合わせて**40手**（1人20手）で打ち切り、拾った数が多い方の勝ち、同じなら引き分け（叩き台）。各自の陣に、その人自身の残り手数が5以下になったら「のこりN手」を出す（合計の数を出すと自分の手数に読めるため。2026-10-15 ui係）
- 先手は毎回交代（1局目は手前の青、2局目は向こうの赤…）。「はじめから」でも1局と数えて交代する
- 勝ち数は数えない。進み具合は保存しない（あそびかたを見たかどうか `oshiai` = `{seen:1}` だけ）

## 画面（向かい合い専用）
- 盤は真ん中。縦持ちは上下、横持ちは左上と右下に各自の陣。向こうの陣は180度回す
- 陣：手番（あなたの番／あいての番・いまの段階）・次に拾う宝・拾った数・手持ち（持っている側だけ）・はじめから
- 手番でない側は薄くする。手持ちは押し出された1枚が飛んでいった側（次の人）の枠に出る
- 手持ちを向こうの陣に描くときは、タイルを180度回して描く（陣ごと180度回っているので、画面の上で盤と同じ向きに見える）
- 宝は番号なしの丸（淡い地に色の縁）。自分の宝は持ち主の色、共通の宝は金（どちらの色でもない）。次に狙う宝は縁を太く濃く、共通の宝はどちらかが狙い始めるまで薄く。陣の「次に拾う宝」は自分の宝 → 金の宝に替わる。拾った数は「拾った n/2」
- 押し込み口の矢印は4辺すべて（8つ）。押す段階だけ押せる。押せる範囲は余白＋端の1マス（動かす段階では矢印を切り、マスのタップを受ける）
- 押し込みの動き（手持ち→口・列が1マス滑る・出た1枚が枠の外まで滑り出て次の人の手持ちへ飛ぶ・駒の回り込み）は oshidashi の流れを写す
- 決着：各自の側に「かち」「まけ」「ひきわけ」（上は180度回す・はやつかみ／かぶせっこと同じ）、打ち切りのときだけ下に「40手で 自分対相手」、真ん中に「もう一局」
- あそびかた：6行の板を上下2枚（上は180度回す）。初回だけ自動、以降は右上の「？」。左上に「‹ パズル箱」（`../#puzzle`）
- 幅360pxの縦持ち・横持ちとも横スクロールなし。押す対象は44px以上（盤のマスは幅360・高さ560で約45px）

## 記法（`window.Oshiai`）
- 状態 `{cells[25], hand, piece:[青,赤], tre:[[自分の宝],[自分の宝]], next:[青,赤], turn, phase:'push'|'move', ban, turns, first, over, winner}`
  - 腕 N=1 E=2 S=4 W=8。自分の宝の位置は盤のマス／-1=手持ち／-2=拾った。共通の宝は `COMMON`=12（動かない）。`next` 0=自分の宝を狙う 1=共通の宝を狙う 2=拾った（勝ち）。`target(状態, 人)` が次に狙うマス（-1=手持ち／-2=拾い終えた）。`ban`=次の押し込みで使えない口（直前の口 op の op^1）。`winner` -1=引き分け
  - 押し込み口: 0=行1左 1=行1右 2=行3左 3=行3右 4=列1上 5=列1下 6=列3上 7=列3下
- `GOAL`=2・`OWN`=1・`MAX_TURNS`=40・`COMMON`=12・`target`・`newGame({rng, first})`・`isSymmetric`・`legalOps`・`push(状態, 口, 手持ちの向き)`・`reachable(状態, 人)`・`pathBetween`・`moveTo(状態, マス)`・`variants`・`rotate`・`mirror`
- DOM に依存しない。`tools/selfplay.js` が vm で読み込んで指す

## 自動対局の実測（2026-10-15・`node tools/selfplay.js 2000`・前の版は `OSHIAI_HTML=` で 789c7f0 の index.html を同じ道具で指す）
| 対局 | 版 | 手数（二人の合計）中央値／四分位 | 打ち切り | 引き分け | 決着した局の先手の勝率 |
|---|---|---|---|---|---|
| ランダム同士 | v0.1（宝3・60手） | 60／60〜60 | 94% | 42% | 50% |
|  | **v0.2（自分の宝＋共通・40手）** | 40／40〜40 | 86% | 51% | 49% |

|  | **v0.2** | 6／5〜10（最短3） | 0.5% | 0.4% | **58.3%** |
| 守り手同士（相手の次の一押しで拾える手を最小に） | v0.1 | 60／60〜60 | 90% | 47% | 54.5% |
|  | **v0.2** | 40／40〜40 | 79% | 52% | 58.7% |
- 盤はすべて180度対称・はじめの宝は不通・押し込みの選択肢は毎回7（最小）
- 守り手は1手先の相手の全応手（口×向き）を見て塞ぐので、人より強く守る。打ち切りを80手にしても守り手同士の打ち切りは63%（1000局）で、手数を延ばしても決着は増えにくい
- 先手の有利は v0.1 より約4ポイント大きくなった（貪欲・守り手とも約58%）。先手を毎局交代して打ち消す
