v0.3：**先手の最初の手番は押すだけ**（駒は動かせない）。先手の有利を縮める（オーナー了承 2026-10-15。下の「先手の有利を縮める案の比べ」）

v0.2：宝は1人2つ（自分の色の宝 → 真ん中の共通の宝）、共通の宝を先に拾った方の勝ち、打ち切り40手（オーナー決定「冗長になりすぎる」への対策。v0.1 は自分の宝①②③を先に3つ・60手）

おしだし（ひとり用）の押し込みの仕組みで、二人が宝を取りあう。スマホを机に置き、二人が向かい合って座る。

## 盤（毎回ランダム）
- 5×5。タイルは3種（直線・かど・三叉＝3:4:3、おしだしと同じ）。押せる列は1つおき（0始まりで1・3の行と列）。偶数行かつ偶数列のマスは動かない
- **盤の中心について180度回転で対称**：マス i のタイルを180度回したものがマス 24−i に入る。中心（12）は自分自身と対になるので直線だけ（十字のタイルは無いので直線のまま）
- **四隅は内向きのかどに固定**（四隅は動かないので、外向きだと駒が出られなくなる）
- 駒：手前の人＝青がマス20（手前から見て左下）、向こうの人＝赤がマス4（向こうから見て左下）
- 宝は1人2つ。**1つ目は自分の色の宝**：四隅と中心を除く10対から1対を選び、対の片方を青、もう片方を赤の宝にする。**2つ目は二人共通の宝（金）**：盤の真ん中（12）。真ん中は動かないマスなので押し出されず、180度対称で両者に同じ条件になる唯一のマス
- はじめから自分の宝に道がつながっている盤は配り直す（押さずに拾えてしまう）
- 手持ち：1枚（3種からランダム）を二人で共有

## 手番
1. **押し込む（必ず）**：手持ちを押し込み口から入れ、列を1マスずらす。押し出された1枚（と乗っている宝）が**次の人の手持ち**になる。押す前に手持ちはタップで何度でも回せる
   - **相手がたった今押した列を、その口の反対側から押し戻すのは禁止**（その矢印を薄くする）。押し込み口は8つなので、打てる押し込みは毎回7つ以上ある
   - 押すと**両方の駒・両方の宝**が列と一緒に動く。押し出された宝は手持ちに乗り、次の押し込みで入口のマスに入る。押し出された駒は反対の端（入ってきた1枚の上）へ回り込む
   - **先手の最初の手番（一局の1手目）は押すだけ**：押した時点で手番が終わり、駒はその場にとどまる（「動かす」段を飛ばす）。2手目からは二人とも普通（この押すだけの手番も、40手の打ち切りの1手に数える）
2. **自分の駒を動かす**：道がつながっている範囲の好きなマスへ（届くマスを薄く塗る）。自分の駒のマスをタップすると「とどまる」
   - **次に狙うマスで止まったら拾う**（途中で通っただけでは拾わない）。順番は自分の宝 → 共通の宝。相手の色の宝は拾えない。自分の宝を拾う前は共通の宝に止まっても拾えない。駒どうし・駒と宝は同じマスに乗ってよい

## 勝ち
- **共通の宝を先に拾った方の勝ち**（その時点で終局。相手が自分の宝をまだ拾っていなくても）
- 二人合わせて**40手**（1人20手）で打ち切り、拾った数が多い方の勝ち、**同じなら延長戦**（下）。各自の陣に、その人自身の残り手数が5以下になったら「のこりN手」を出す（合計の数を出すと自分の手数に読めるため。2026-10-15 ui係）
- 先手は毎回交代（1局目は手前の青、2局目は向こうの赤…）。「はじめから」でも1局と数えて交代する。延長戦の先手は数えない（本戦の先手を基準に交代）

## 延長戦（v0.4）
- 本戦が40手の打ち切りで**拾った数が同じ**（0対0・1対1）なら延長戦。拾った数が違えば今まで通り多い方の勝ち
- 盤は**新しく配り直す**（180度対称・四隅は内向きのかど・駒は出発点）。**自分の宝は無し**で、最初から**真ん中の共通の宝だけ**を狙う。**真ん中のタイルは十字**（延長戦だけ。180度回して同じ形は直線と十字だけ）。はじめから真ん中に道がつながる盤は配り直す
- 合わせて**20手**。**1手目は押すだけ**。**先手は本戦の後手**
- 延長戦も20手で打ち切りなら、**同じ延長戦をもう1回**（盤を配り直し・先手は交代＝本戦の先手）。それでも決まらなければ引き分け
- 画面：同点の打ち切りで決着の板に「延長戦」と「40手で n対n」「真ん中の宝だけ・20手」、ボタンは「延長戦へ」。2回目は「もう一度 延長戦」「20手で決まらず」だけ（同じ規則の繰り返しなので）。十字は盤で見えるので文字にしない。延長戦中は陣の「拾った n/2」の代わりに「延長戦」／「延長戦2回目」、のこり手数は延長戦の20手で数える。延長戦で決まったら決着の下に「延長戦で」「延長戦2回目で」、2回とも決まらなければ「延長戦2回でも決まらず」（2026-10-15 ui係）
- あそびかたの板は、横持ちでは上下でなく左右に並べる（高さ約360pxに8行×2枚が入らない。陣の並びと同じ）
- 記法：状態に `ext`（0=本戦 1・2=延長戦の何回目か）と `extend`（同点の打ち切りで延長戦に入る）。同点の打ち切りは `over`・`winner=-1` のまま `extend=true` になり、`extend(状態, {rng})` が延長戦の盤を返す。`limit(状態)`＝この段の打ち切りの手数。`EXT_TURNS`=20・`EXT_MAX`=2
- 勝ち数は数えない。進み具合は保存しない（あそびかたを見たかどうか `oshiai` = `{seen:1}` だけ）

## 画面（向かい合い専用）
- 盤は真ん中。縦持ちは上下、横持ちは左上と右下に各自の陣。向こうの陣は180度回す
- 陣：手番（あなたの番／あいての番・いまの段階）・次に拾う宝・拾った数・手持ち（持っている側だけ）・はじめから
- 手番でない側は薄くする。手持ちは押し出された1枚が飛んでいった側（次の人）の枠に出る
- 手持ちを向こうの陣に描くときは、タイルを180度回して描く（陣ごと180度回っているので、画面の上で盤と同じ向きに見える）
- 宝は番号なしの丸（淡い地に色の縁）。自分の宝は持ち主の色、共通の宝は金（どちらの色でもない）。次に狙う宝は縁を太く濃く、共通の宝はどちらかが狙い始めるまで薄く。陣の「次に拾う宝」は自分の宝 → 金の宝に替わる。拾った数は「拾った n/2」
- 押し込み口の矢印は4辺すべて（8つ）。押す段階だけ押せる。押せる範囲は余白＋端の1マス（動かす段階では矢印を切り、マスのタップを受ける）
- 押し込みの動き（手持ち→口・列が1マス滑る・出た1枚が枠の外まで滑り出て次の人の手持ちへ飛ぶ・駒の回り込み）は oshidashi の流れを写す
- 決着：各自の側に「かち」「まけ」「ひきわけ」（上は180度回す・はやつかみ／かぶせっこと同じ）、打ち切りのときだけ下に「40手で 自分対相手」、真ん中に「もう一局」
- 陣の手番の案内：押す段「矢印で押し込む」、先手の1手目だけ「押し込むだけ・1手目は動かせない」、動かす段「行き先をタップ・●ならとどまる」
- あそびかた：8行（7行目＝先手の1手目は押すだけ・8行目＝40手で同点なら、真ん中の宝だけの延長戦）の板を上下2枚（上は180度回す）。初回だけ自動、以降は右上の「？」。左上に「‹ パズル箱」（`../#puzzle`）
- 幅360pxの縦持ち・横持ちとも横スクロールなし。押す対象は44px以上（盤のマスは幅360・高さ560で約45px）

## 記法（`window.Oshiai`）
- 状態 `{cells[25], hand, piece:[青,赤], tre:[[自分の宝],[自分の宝]], next:[青,赤], turn, phase:'push'|'move', ban, turns, first, over, winner, ext, extend}`（延長戦は上）
  - 腕 N=1 E=2 S=4 W=8。自分の宝の位置は盤のマス／-1=手持ち／-2=拾った。共通の宝は `COMMON`=12（動かない）。`next` 0=自分の宝を狙う 1=共通の宝を狙う 2=拾った（勝ち）。`target(状態, 人)` が次に狙うマス（-1=手持ち／-2=拾い終えた）。`pushOnly(状態)` がこの手番は押すだけか（`turns`=0）。押すだけの手番では `push` が駒をとどめて手番を終えた状態（相手の押す段）を返す。`ban`=次の押し込みで使えない口（直前の口 op の op^1）。`winner` -1=引き分け
  - 押し込み口: 0=行1左 1=行1右 2=行3左 3=行3右 4=列1上 5=列1下 6=列3上 7=列3下
- `GOAL`=2・`OWN`=1・`MAX_TURNS`=40・`COMMON`=12・`EXT_TURNS`=20・`EXT_MAX`=2・`target`・`pushOnly`・`limit`・`extend(状態, {rng})`・`newGame({rng, first})`・`isSymmetric`・`legalOps`・`push(状態, 口, 手持ちの向き)`・`reachable(状態, 人)`・`pathBetween`・`moveTo(状態, マス)`・`variants`・`rotate`・`mirror`
- DOM に依存しない。`tools/selfplay.js` が vm で読み込んで指す

## 延長戦の狭め方の比べ（2026-10-15・`OSHIAI_EXT=案 OSHIAI_POL=greedy,blocker1,blocker node tools/selfplay.js 4000`）
延長戦だけを4000局（先手を交互）指した 決着率／決着した局の先手勝率／決着局の手数の中央値。最後の列は守り寄り同士の1局全体の引き分け率（本戦4000局に延長戦を足す前→後）
| 案 | 貪欲 | 見える範囲だけ邪魔 | 守り寄り | 引き分け（守り寄り） |

| **E3 E1＋真ん中を十字（採用）** | 100%／34%／3 | 100%／33%／3 | **59%／49%／7** | →18.7%（**もう1回で→8.0%**） |

- 貪欲・邪魔は本戦の引き分けが0.3〜0.5%で、どの案でも延長戦後は0%。効くのは守り寄り同士だけ
- E4 の候補（守り寄り）：12手（E1→23%・E3→47%で決着が減る）／1手目の押すだけを外す（E3で決着72%だが先手82%）／二人とも1手目は押すだけ・先手は押すだけ→後手は動かすだけ（偏りが逆へ移るだけ）。三叉は180度対称にならない

- 採用後の index.html を既定（`node tools/selfplay.js 4000`）で指した値：守り寄り同士は延長戦に入る48.0%・1回目で決着58.7%・決着した延長戦の先手勝率45.7%・延長戦の手数の中央値15・1局全体の引き分け8.2%・決着した局の先手勝率50.0%（守り手 2000局：入る56.1%・1回目で決着61.0%・引き分け8.7%）。貪欲・邪魔は引き分け0%
