# おしあい（oshiai）

おしだし（`../oshidashi/`）の**対戦版**。1台のスマホを机に置き、**二人で向かい合って**遊ぶ。箱の「ふたりで」3本目。
単一HTML（`index.html`）。ブラウザで開くだけで動く。ライブラリ・APIキー不要。コードは他と共有しない（おしだしのロジックは写して持つ）。

## 正典地図
- 仕様（盤・手番・押し込み・駒と宝・勝ち・画面）: `docs/spec.md`
- AIガイドライン（触るなリスト）: `docs/ai_guidelines.md`
- 決定ログ: `docs/decision_log.md`（迷って決めた判断は Vault `10.Projects/パズル箱/90_開発ログ.md` にも書く）
- 自動対局: `tools/selfplay.js`（`index.html` の `window.Oshiai` を読み込み、ランダム同士・貪欲同士・守り手同士で指して手数・引き分け・先手の勝率と盤の対称を確かめる）
- 思想: `../../../template/owner_context.md`（コピー禁止）

## 憲法（変えない原則）
- **毎回ランダムな盤。タイル・駒・宝の置き方は盤の中心について180度回転で対称**（先手・後手の条件を同じに）。問題集にしない
- 手番＝**押し込み1回（必ず）→ 自分の駒を道のつながる所へ動かす（とどまってもよい）**。回すのは自由
- 押し込みは**両方の駒・両方の宝**を一緒に動かす。宝は押し出されたら手持ちに乗り、駒は反対の端へ回り込む
- **相手がたった今押した列を、その口の反対側から押し戻すのは禁止**（おしだしの打ち消しの禁止と同じ）
- 宝は1人2つ：**自分の色の宝 → 真ん中の共通の宝**の順に、**止まったときだけ**拾う。**共通の宝を先に拾った方の勝ち**（2026-10-15 オーナー決定）。宝は**両方とも見える**
- 相手側の表示は180度回す。元になったボードゲームの名前・絵・駒の形は使わない
- 実機（スマホを二人で囲む）で遊ぶまで「完成」と言わない。迷って決めた判断が出たら決定ログへの記録を促すこと
