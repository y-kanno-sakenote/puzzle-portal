# おしだし（oshidashi）

盤の端から手持ちのタイルを押し込んで列を1マスずらし、駒（●）を宝①②③の順に回らせるパズル（2026-10-15 宝を順に回る規則に作り直し）。
単一HTML（`index.html`）。ブラウザで開くだけで動く。ライブラリ・APIキー不要。

## 正典地図
- 仕様（盤・押し込み・回転・駒と宝・段・記法）: `docs/spec.md`
- AIガイドライン（触るなリスト）: `docs/ai_guidelines.md`
- 決定ログ: `docs/decision_log.md`（迷って決めた判断は Vault `10.Projects/パズル箱/90_開発ログ.md` にも書く）
- 問題生成器: `tools/gen_levels.py`（幅優先＋深さ優先で最短手数を出し、条件を満たす盤だけを `tools/levels.json` と `index.html` に埋め込む）
- 思想: `../../template/owner_context.md`（コピー禁止）

## 憲法（変えない原則）
- 1手＝押し込み1回。**回すのは手数に数えない**。最短手数はBFSで機械的に出す。手で盤面を書かない
- **直前の押し込みを打ち消す口（いま押し出された1枚が出た口）は次の1手で使えない**。手数の意味を保つため
- 押せる列は1つおき（0始まりで奇数番目の行・列）。偶数行かつ偶数列のマスは動かない
- 宝はタイルに乗って列と一緒に動き、押し出されたら手持ちに乗る。駒は「次の宝まで道がつながったとき」だけ自分で進んで拾う。最後の宝を拾えばクリア
- 元になったボードゲームの名前・絵・駒の形は使わない。立体表現・協力・続き物・日本酒テーマ・音・タイマー・ヒントは足さない
- 実機（ブラウザ・スマホ）で遊ぶまで「完成」と言わない
- 迷って決めた判断が出たら、決定ログへの記録をユーザーに促すこと
