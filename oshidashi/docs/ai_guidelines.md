# おしだし AIガイドライン

## 第0章 なぜ
パズル箱に「**列ごとずらす**」動詞を入れる。くるくる（1マスを回す）・車をだせ（1台を滑らせる）と違い、
1手で列全体と駒・宝が一緒に動き、押し出された1枚（と乗っている宝）が次の手持ちになる。
2026-10-15 に「宝を順に回る」へ作り直した（最短3〜4手・動かないゴール1つでは、一つひらめけば終わり旅が無かった）。
核は**区間をまたぐ読み**：次の宝を一番早く拾う手が、その次の宝には遠回りになる。宝を一度押し出して入れ直すのも手

## 触るなリスト
- 1手の定義（押し込み1回。回転は数えない）／打ち消しの禁止
- 押せる列は奇数番目・偶数×偶数のマスは動かない
- 駒が押し出されたら反対側の端（入ってきた手持ちのタイルの上）に回り込む／宝は押し出されたら手持ちに乗り、次の押し込みで入口のマスに入る
- 拾うのは番号順だけ。駒は次の宝まで道がつながったときだけ進む（自分では歩かない）
- 押し込み口の番号の付け方（生成器・`window.Oshidashi`・`levels.json` の `sol` が共有している）
- 埋め込み問題（`tools/gen_levels.py` の出力以外で書き換えない。手直しするなら生成器を直して再生成）
- 「足さないもの」の一覧（spec.md）

## 第2章 事故と学び（事故のたびに育てる）
- （くるくる・みちつなぎから継承）セル寸法は枠線を含めずに測る。SVG の user unit は整数で置く
- 2026-10-14 生成の試し測りで、`python3 - <<EOF` から multiprocessing を spawn すると子が `<stdin>` を読みに行って無限に失敗し、ログが 64MB を超えた。学び: **multiprocessing を使う計測は必ずファイルに書いたスクリプトから**走らせる
- 2026-10-15 宝つきで最短6手の盤は、素の深さ優先だと1本3分かかる外れ値が並列を止めた。学び: **最後の1〜2手は「押す列が駒と次の宝の間をまたげるか」の必要条件で枝を刈る**（呼び出し約1/5）。それでも重い盤は打ち切って捨てる（最短が不確かな盤は採らない）
