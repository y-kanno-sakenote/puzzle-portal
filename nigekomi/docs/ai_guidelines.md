# にげこみ AIガイドライン

## 第0章 なぜ
スマホ広告でよく見る「点と線の上を追っ手から逃げて家に入る」遊びを、運でなく読みで解く詰将棋にする。
鬼の動きが決まりどおりで、遊び手が先を読めることが唯一の売り。

## 触るなリスト
- 規則（1手の定義・勝ち負けの判定順・鬼の動き方）。変えると埋め込み40問の最短手数が全部嘘になる
- 「いらない線が0本」（消しても (1)〜(4) が保たれ罠の手の数も減らない線が無い）・同型の重複0・読みどころの下限の採用条件
- 上級の採用条件 (a) 2体とも効いている (b) 最短解の筋で重ならない、と段ごとの勝率の帯（重ねない）
- 「到達しうる全局面で鬼の行き先が1つ」の採用条件。12時から時計回りの決めごとは保険で、採用した地図では一度も使われない
- 埋め込みレベル（`/* LEVELS-BEGIN */`〜`/* LEVELS-END */`）。手直しするなら生成器を直して再生成し `--keep tools/levels.json --embed index.html` で貼る
- 進み具合の保存キー `nigekomi` と `{cleared:{idx:1}, last}` の形（入口 `../index.html` が読む）
- レベルの並び順（クリア記録が index 依存。段を足すなら末尾に追記）
- 「足さないもの」の一覧（spec.md）

## 第2章 事故と学び（事故のたびに育てる）
- 2026-10-02 上級（鬼2体）が見かけ倒しだった（qa 独立検証）。最短解の筋で途中から2体が重なり実質1体、1体外しても最短が同じ問が多数。学び: **駒を足した段は「足した駒が効いている」ことを機械で確かめる**（外して解き直す・重なりを最短解の全筋で調べる）。最短手数だけでは難しさが逆転するので、でたらめに選ぶ人の勝率も目安に持つ
- 2026-10-02 「どの線を消しても最短が変わる」まで削り切ったら、一本道に近い地図になり、同型の描き直しが7組出た（qa）。学び: **最短解に効かない線でも、罠（迷う分かれ道）を作る線は遊びの中身**。減らすときは「何が減るか」を数で見る。座標の Jaccard は同型を見逃すので、役割つきの正準形でも比べる
