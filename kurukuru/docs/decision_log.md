# くるくる 決定ログ（直近が上）

| 日付 | 決定 | 捨てた案 | 理由 |
|---|---|---|---|
| 2026-09-13 | 一意性は「向きの重複を同一視した上で」判定する | 向きの列がぴったり一致することを一意性とする | 直線の180度・十字の全方向は見た目も接続も同じ。区別すると解が常に複数になり判定が意味を失う |
| 2026-09-13 | つながっている所を光らせる | 光らせない | 盤の状態をそのまま描いているだけで、隠された答えを明かしていない。進み具合が見えるのがこのジャンルの快感 |
| 2026-09-13 | 操作はタップで時計回りだけ | 逆回転・長押し・ドラッグ | 4回で一周するので逆回転が無くても到達できる。操作を増やすと手触りが濁る |
| 2026-09-13 | 元の網は木（閉路なし）。盤の外へ出る腕も作らない | 閉路あり／外へ出る腕あり | 閉路や外向きの腕があると一意解になりにくく、初手の手がかりも減る |
